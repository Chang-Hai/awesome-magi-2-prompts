## 作例　雨のホームから列車が出発するワンカット

**テキストから動画** · 10 秒 · 21:9 · 参照素材なし

```text
日没後の青い薄明かりの中、誰もいない地上駅のホームを腰の高さから広角でワンカット撮影する。画面右側には地域を結ぶ列車が停車している。細かい雨がホームの照明に浮かび、コンクリートの床に淡い反射をつくる。カメラは固定する。冒頭では雨音と停車中の列車から響く低い駆動音が聞こえる。4秒の時点で短いドアチャイムを一度鳴らし、画面内のドアが閉まりきる。6秒の時点で列車が右へ動き出し、画面から出るにつれて駆動音が遠ざかる。最後の1秒は誰もいないホームを映し続ける。
```

ドアが閉じてから列車が動き出すこと、ホームの形が途中で変わらないことを確認します。ドアチャイム、列車の動き出し、駆動音が遠ざかる順番も確認してください。
